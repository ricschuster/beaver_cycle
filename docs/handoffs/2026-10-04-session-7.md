## Completed

- PR #62: `src/terrain/trees.ts` places trees from a tile's class map with a
  seeded generator (level 0 forest 1 per 70 m2 and scrub 1 per 400 m2, level 1
  forest 1 per 280 m2 with trees 1.8 times bigger, level 2 none). Nothing is
  stored. `terrainView.ts` now builds one group per tile: terrain, lake quads
  at the tile's lake level over class 9 cells (levels 0 and 1, slightly
  transparent), stream ribbons draped on the ground (2.5 m wide, levels 0 and
  1), and an instanced tree mesh. Tree geometries are shared and never
  disposed. `sampleHeight` moved into `format.ts` so trees and the store use
  the same triangles. The streamer takes an optional `fetchWater` and loads
  `water/<tx>_<tz>.json` for nearby tiles with water. Tests for tree placement
  and water geometry. Closed #51.
