  from tiles at seed time. Unit tests for the rule; test spots in `cycle.test.ts`, `partners.test.ts`, and `upkeep.test.ts` now have
  `maxCrest: 2`.

  So the old "room for a lodge within 300 m" rule could never hold at stream spots. The author's point settled it: a dam spot can be
  dammed, so a lodge can be built there.
