## Summary

A talk froze the game after "Bye" (and after any line). The cause was the recorded babble from session 93: `webAudio.ts` called
`src.stop()` before `src.start()`, which the browser rejects with an error, and the error stopped the frame loop. Fixed in #430.

- Checked: typecheck, the repro run. The repro spec was deleted, not committed.
