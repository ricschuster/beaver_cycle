  shadows choices are kept in `localStorage` (`src/ui/prefs.ts`). The renderer builds shadows only at the start, so the shadows
  button saves the game and reloads. Manual text added.
- #553 (merged): `tests/release/release.spec.ts` on `vite preview` (`npm run test:release`, 4 tests, in the CI `build` job); the six
  manual pictures retaken.
