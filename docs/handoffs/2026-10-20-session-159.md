# Session Handoff: 2026-10-20 (session 159)

## Summary

The multiplayer pieces that stand alone were built, then the network itself: a guest tablet joins a host over the WLAN and its
beaver walks, swims, and gnaws trees in the host's world. It was played on two SM-X210 tablets in the real valley.

## Completed

- #675 (#660): `startFamilies` puts up to four more families on rings round the home lodge at a new game. Automated browsers skip
  them unless `?families=1`. Merged.
- #676 (#663): a Give button. With food in the mouth and a family beaver with an empty mouth within 4 m, Do reads Give. Merged.
- #677 (#662): the host server plugin (`tools/host-server/`, a WebSocket server in the app), the dot spike (`tools/net-spike/`),
  and ADR 0014. Merged.
- #679 (#678): guest beavers. `src/sim/guests.ts`, `src/net/` (protocol, room, view, session), wired in `main.ts` behind `?host=1`
  and `?join=IP`. Open when this handoff was written, merge it first.

## Current state

- Transport: Java-WebSocket in a Capacitor plugin, JSON text, port 8765, the guest types the host's IP. Measured about 30 ms
  round trip, 20 states a second. A laptop browser can join; only the app can host.
- The release app needs `server.cleartext: true` and `android.allowMixedContent: true` or `ws://` is blocked from
  `https://localhost`. Both keep the origin, so saves stay. `tools/standalone-apk/` has neither the plugin nor the settings yet.
- A guest shows the host's clock, felled trees, and logs, and its own beaver where the host puts it. It never saves.
- Not shared yet: dams, ponds, lodges, food, carrying, families, sleep and skip. The host's beaver has no leg movement on a guest.
  The guest places itself by the host's beaver, not at a free lodge. There is no Host or Join screen.
- To run it on tablets: `tools/host-server/apply.sh tools/tablet-live/android`, build and install the live shell, `npm run dev`,
  `adb reverse` per tablet. The live shell loads a fixed URL, so I used a small redirect on two ports to add `?host=1` and
  `?join=IP` (a throwaway script in the session scratchpad, not in the repo).
- Not run: e2e, a tablet run of the release build, more than one guest at a time, a guest tablet that sleeps and wakes.
- Seen on the tablet: the look card's Go button sits below the visible card and needs a scroll.
