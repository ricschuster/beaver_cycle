# Session Handoff: 2026-10-20 (session 160)

## Summary

Playing together can now be started by players: the start screen hosts and joins, the standalone APK can host, and a guest keeps its
own outfit. It was tried on two SM-X210 tablets with the real APK, one hosting and one joining, and works.

## Completed

- #682 (#681): a Play together section in Settings, then moved out (below). `src/net/pending.ts` keeps the address to join in the
  session storage across the restart, `lastHost` is in the prefs. Merged.
- #683: `apply_shell.py --host` adds the HostServer plugin and the INTERNET permission to the standalone APK; `apply.sh` registers
  the plugin in our own MainActivity; `capacitor.config.json` has `server.cleartext` and `android.allowMixedContent`. The Play
  bundle is built without `--host`. Merged.
- #684: a guest keeps its own coat and look (the Join kept them with the address). Merged.
- #685: host and join on the start screen. A tick, Let friends join this game (app only), hosts the slot you continue and shows
  the address in a toast. An address and Join restart the game as a guest, who picks a look on the look card. Settings keeps the
  status line and Leave for a guest. Merged.
- #686: the start screen Join saved the prefs through `keptPrefs`, which reads the minimap before it exists, so the game stopped with
  only the controls drawn. Fixed. Open when this handoff was written, merge it first.
